# Домашнее задание.

## Описание:

Данный проект разрабатывается в рамках домашних заданий курса. Натекущий момент содержит функционал:
1. По маскеровке введенных номеров карт и аккаунтов;
2. По сортировке данных.
3. По сортировке транзакций в рамках выбранной валюты
4. По выводу описания транзакций
5. Генератор номеров карт
6. Декоратор для логирования результата выполнения функции
7. По получению списка транзакций из json-файла
8. По выводу суммы транзакций и конвертирования ее в рубли
9. Для считывания финансовых операций из csv-файла
10. Для считывания финансовых операций из xlsx-файла

## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Python_task_10_1)
2. Установите зависимости
   (`pip requirements.txt`)

## Использование:

1. Откройте проект.
2. Введите данные, запрашиваемые функциями.
